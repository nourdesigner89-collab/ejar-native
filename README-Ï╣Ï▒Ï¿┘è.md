# تحويل اجار إلى تطبيق Android حقيقي — بدون كمبيوتر

هذا الدليل يشرح لك كيف تبني ملف APK حقيقي **من جوالك فقط**، بدون لابتوب أو Android Studio. البناء يصير على سيرفرات GitHub المجانية.

---

## أولًا: أنشئ حساب GitHub (مرة وحدة بس)

1. افتح متصفح جوالك وروح لـ github.com
2. اضغط Sign up
3. اكتب إيميلك وكلمة مرور واسم مستخدم
4. أكمل خطوات التسجيل (مجاني بالكامل)

---

## ثانيًا: أنشئ مستودع (Repository) جديد

1. بعد تسجيل الدخول، اضغط على علامة + بأعلى الصفحة
2. اختر "New repository"
3. اكتب اسم زي: ejar-native
4. خلّيه Public (عام) — عشان يصير عندك دقائق بناء مجانية غير محدودة
5. اضغط "Create repository"

---

## ثالثًا: ارفع ملفات المشروع

1. بنفس صفحة المستودع الفاضي، بتلاقي رابط مكتوب "uploading an existing file" — اضغطه
   (لو ما ظهر، اضغط زر "Add file" ← "Upload files")
2. فك ضغط ملف ejar-native.zip اللي أرسلته لك على جوالك (فيه تطبيق فك ضغط جاهز بمعظم الأجهزة، أو نزّل تطبيق "ZArchiver" مجاني)
3. من صفحة الرفع بجيت‌هَب، اسحب أو اختر **كل الملفات والمجلدات** اللي جوا مجلد ejar-native (بما فيها مجلد .github ومجلد www بكل محتوياتهم)
4. مهم: لازم تحافظ على نفس ترتيب المجلدات بالضبط
5. تحت الصفحة، اكتب أي وصف بسيط بخانة "Commit changes"
6. اضغط "Commit changes"

---

## رابعًا: شغّل عملية البناء

1. اضغط على تبويب "Actions" بأعلى صفحة المستودع
2. بتلاقي عملية بناء بدأت تلقائيًا (لأنك رفعت ملفات جديدة) اسمها "Build Android APK"
3. اضغط عليها لتشوف تفاصيلها
4. انتظر — تاخذ عادة 5 إلى 10 دقائق
5. علامة صح خضراء ✅ تعني نجح البناء. علامة X حمراء تعني صار خطأ (خذ لي لقطة شاشة وأساعدك)

---

## خامسًا: نزّل ملف الـ APK

1. بنفس صفحة عملية البناء الناجحة، انزل لأسفل
2. بتلاقي قسم اسمه "Artifacts"
3. اضغط على "ejar-debug-apk" لتنزيله (بينزل كملف مضغوط فيه الـ APK جواه)
4. فك ضغطه، وثبّت ملف الـ APK على جوالك بنفس طريقة المرات اللي قبل

---

## ملاحظة مهمة

هذا الإصدار "Debug" (تجريبي) — يشتغل تمام للتجربة والاستخدام الشخصي، لكن لو حبيت تنشره على جوجل بلاي لاحقًا، بنحتاج خطوة إضافية بسيطة لتوقيعه بشكل رسمي (Release). خبرني أول ما تنجح بتشغيل هذا الإصدار ونكمل.

---

## قبل أي تجربة — لا تنسى

روح لإعدادات Firebase وأضف نطاق جديد:

1. console.firebase.google.com ← مشروعك
2. Authentication ← Settings ← Authorized domains
3. Add domain
4. اكتب: `localhost`
5. احفظ
